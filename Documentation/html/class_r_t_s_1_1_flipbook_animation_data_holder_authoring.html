Detailed Description

Authoring component for the FlipbookAnimationDataHolder ECS component. This component creates bake-time only sub-entities for each frame of each animation type defined in the FlipbookAnimationSetScriptableObject. Each sub-entity is assigned a RenderMeshUnmanaged component with the corresponding mesh and a MaterialMeshInfo component. The main entity is assigned a FlipbookAnimationDataHolderObjectData component referencing the animation set ScriptableObject and a FlipbookAnimationDataHolder component to hold the BlobAssetReference for the animation data.
