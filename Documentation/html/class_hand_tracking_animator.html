Detailed Description

Obtains autoHandLeftHand tracking data and updates finger rotations.

  • A DefaultExecutionOrder is set, otherwise the fingers get wrong positions when the TwoBoneIKConstraintDisjointed disjoints the shoulders.
    • Note: Strangely, a value of 2 does not work.
    • This also allows the AutoHand joints to be set after AutoHand has set rotations.
