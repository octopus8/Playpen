Detailed Description

This component is attached to a O8CMirrorNetworkPlayer to provide access to a player's Microphone Pro ID.

  • If the player is the local player, the Start method of this component obtains and stores the MicrophonePro ID. This results in calling the hook OnMicrophoneProIDChanged being called for this instance and remote instances of this player.
