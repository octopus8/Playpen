Detailed Description

Sets finger bends for the specified finger bend type upon the corresponding input.

  • It is expected that multiple instances of this component are attached to a single hand to handle multiple finger bend types.

Each hand may have multiple instances of this component to handle different finger bend types. To produce an additive effect of the inputs, upon the call of the first update each frame, the offset values are reset. This set of flags is used to perform the offset value resets.
