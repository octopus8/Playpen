Detailed Description

  • Buffering of tracking data: WebXRController returns tracking data via a callback. In order to synchronize the data with FixedUpdate, the data received from WebXRController is buffered and stored on FixedUpdate. If this is not done, the data could be used, then updated by WebXRController then used again. This is necessary for the HandTrackingAnimator to work correctly.

Future Development Notes:

  • Maybe the left and right controllers don't need to be via the editor. Maybe they should be obtained via the O8CSystem.
