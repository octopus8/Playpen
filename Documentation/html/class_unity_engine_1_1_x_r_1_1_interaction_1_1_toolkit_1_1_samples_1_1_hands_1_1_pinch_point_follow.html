Detailed Description

A class that follows the pinch point between the thumb and index finger using XR Hand Tracking. It updates its position to the midpoint between the thumb and index tip while optionally adjusting its rotation to look at a specified target. The rotation towards the target can also be smoothly interpolated over time.
